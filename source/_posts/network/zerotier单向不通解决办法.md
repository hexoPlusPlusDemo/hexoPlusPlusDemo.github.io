# 问题：笔记本无法打通服务器

最近不知道为什么，笔记本总是没办法打通服务器，但是发现服务器能很快的ping通笔记本，于是在服务器上添加了一个定时任务，每一分钟向笔记本发送一次ping请求，因为我的笔记本能够与zerotier组网中其他的设备连接，具体为什么打不通服务器还需要排查，当前的解决办法非常的迅速。

```bash
echo "*/1 *   * * *   root    ping 172.29.10.237 -c 1"  >> /etc/crontab
```
